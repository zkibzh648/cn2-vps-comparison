## 什么是 CN2，为什么它成了"购买关键词"

CN2 是中国电信下一代承载网（Next Carrier Network）的简称，骨干节点走的是 59.43 段 IP，比老一代 163 骨干网的设计标准更高。CN2 又细分成 GT 和 GIA 两档：

- **CN2 GT**：去程走 CN2，回程可能回落到 163，体验比普通线路好，但晚高峰偶尔会受影响。
- **CN2 GIA**：去程和回程都强制走 CN2 高速节点，是 CN2 家族里定位最高的产品，丢包率极低，延迟稳定。
- **AS9929 / CMIN2**：分别是联通和移动的精品回程线路，单独走 CN2 GIA 只优化了电信方向，搭配 9929 和 CMIN2 才能做到"三网都优"。

很多人买完 VPS 才发现晚高峰卡顿，多半就是只优化了去程、回程被打回了 163。所以现在主流的"CN2 VPS 购买"诉求，实际上是要找**三网回程都走精品线路**的产品，而不是单纯挂个 CN2 标签。

## CN2 VPS 选购的几个关键维度

下单前，建议你按下面这张清单逐项对照，比单纯比价格靠谱得多。

1. **回程路由是不是强制优化**：去程优化便宜，回程优化才贵。问客服要回程路由测试，看是不是三网都走 59.43（电信）、AS9929（联通）、CMIN2（移动）。
2. **机房位置**：物理距离决定基础延迟。香港到大陆普遍 30–50ms，日本 50–80ms，新加坡 60–90ms，美西 150–180ms。延迟越低，建站和远程桌面体验越顺。
3. **CPU 单核性能**：很多 VPS 看着核心多，单核频率不高，跑 MySQL、Redis 这类吃单核的应用会拉胯。优先看主频，5GHz 以上的现代处理器体验差距明显。
4. **带宽与流量**：带宽决定峰值速度，流量决定月用量上限。注意看是不是"超流量限速到 20KB/s"还是"按 GB 计费"，前者更常见也更友好。
5. **DDoS 防护能力**：如果你跑游戏服、电商、视频站，被攻击是常态。100Gbps 以下的防护基本等于裸奔，500Gbps 起才算够用。
6. **退款政策**：24 小时无理由退款几乎是这一档商家的标配，没有的话要警惕。
